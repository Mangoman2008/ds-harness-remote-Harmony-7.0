# HarmonyOS 客户端更新记录

## 首次集成

- 提供 HarmonyOS 原生客户端，支持账号登录、Host 选择、多会话及流式回复。
- 支持模型与权限选择、图片和语音输入、会话搜索与归档。
- 支持端到端加密、主机公钥固定、系统安全存储及网络中断恢复。
- 支持 LAN/P2P/TURN/Relay 传输、手机和平板布局、中英文界面与主题切换。

贡献者：[Mangoman2008](https://github.com/Mangoman2008)。

## 集成后的补强

- 权限确认与问答不再丢：审批可能在切到别的会话、或连接刚重连时到达，客户端会先暂存，
  重新打开会话时补发，卡片可以直接作答；主机已经作废的确认会明确显示为「已失效」。
- 连接诊断新增 Host 车道与组合指纹，能看出主机版本落在哪个能力车道、这次连接和上次有何不同。
- 修复预发布版本（如 `0.2.2-rc.1`）被误判到较低能力车道的问题，附件完整引用等能力不再误降级。
- 会话壁纸（默认虚化、三档强度）与桌宠（鲸娘，四态动画、单击说话、双击炸屏、待命睡着）可自行开启，
  素材由使用者自备、不进仓库。
- 链路日志落盘并可在诊断页查看，掉线自动重连后会自动重开会话流。
- 直连数据通道中途断开时，下一次重连会先走中继（首次 60 秒、连续两次 10 分钟内不再试直连），
  不再反复撞同一条不通的路径。
- 审批与提问在 App 处于后台时发一条系统通知（点通知直接回到 App），不用等回到会话才发现主机在等你。
- 会话列表会标出「待确认」，多个会话各挂一张卡时也能一眼看到。
- 跨连接补发出来的确认与提问，卡片上会提示「连接已重连，这条确认可能已失效」。
- 支持发送文件附件：选择文件后先上传到主机暂存，再随消息提交（单个 2.6 MB 以内）。
- 后台提醒更克制：同一条审批/提问只提醒一次（重连补发不会重复响铃），在 App 里答完或切回前台后
  通知自动消失，不会留下过期的「需要确认」。
- 点审批/提问通知会直接落到那条会话，而不是回到上次停留的位置。
- 审批与提问卡片显示已等待时长，超过 10 分钟标红提示「主机可能已超时」，一眼看出这条可能已经废了。
- 诊断页新增「通知」一行（App 内开关 / 系统开关 / 上次发布失败码分开显示）与「自检」按钮：
  一次列出连接、链路、直连、Host 能力、文件上传、通知、待确认、日志落盘情况。
- 主机返回的英文报错按规则翻成可执行的中文提示（含旧版插件、上下文超窗、主机忙、路径越界）。
- 发送失败的消息留在原位，带「重试」；断线时发送改为排队，重连回到该会话后自动补发（含附件）。
- 待发附件显示大小与合计；诊断页新增断线原因归类、RPC 质量（中位/P90）与「自检」结果。
- 诊断导出头部带上客户端/主机/插件版本、系统 API、机型与传输方式。
- 会话设置面板新增「显示桌宠」开关，首页一次点击即可隐藏/恢复桌宠。
- 回复里的 Markdown 表格按表格渲染（表头底色、行分隔、等宽列），不再显示原始的竖线和横线。
- 输入坞的文件键换成矢量图标（不再是 emoji），待发文件 chip 同步换掉。
- 思考过程默认折叠成两行，点「展开/收起」看全文。
- 代码块整段渲染（语言标注 + 单一底色，保留缩进），长按可一次复制整段。
- 会话左栏改版（参考上游）：列表按工作区分组、组头显示条数并可折叠；搜索时改回平铺、不显示分组与筛选。
- 「最近访问」收进搜索框右侧的小入口，默认收起，不再常驻占一行；工作区 chip 长按可浏览文件 / 重命名 / 删除。
- 首页（设备列表）那张会呼吸的立绘改成三选一：内置立绘 / 自定义图片 / 关闭，与桌宠开关分开控制；
  自定义图片会自动压到 512px 以内，选择时给出规格建议（PNG/JPG、约 3:4、≤1 MB）。
- 关掉首页立绘时，连它脚下的影子条一起移除，不再留一条横线。
- 支持自建服务器使用自定义端口：鸿蒙的 WebSocket 不带端口，客户端补一个完整 Origin 头，服务端按它校验（对齐官方 0.6.7）。
- 诊断页显示中继路径：独立中继时给出节点地址与节点 ID，走控制通道转发时明确标注。
- 密码登录支持两步验证：账号开了 2FA 时，输入密码后会多出「验证码或恢复码」一栏，也可点「重新输入密码」重来。
- 会话终端：设置面板里可直接打开当前会话的终端，输出滚动显示、可输入命令（暂不做完整 ANSI 着色）。
