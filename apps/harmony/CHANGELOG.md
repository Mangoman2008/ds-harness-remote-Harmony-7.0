# HarmonyOS 客户端更新记录

## 首次集成

- 提供 HarmonyOS 原生客户端，支持账号登录、Host 选择、多会话及流式回复。
- 支持模型与权限选择、图片和语音输入、会话搜索与归档。
- 支持端到端加密、主机公钥固定、系统安全存储及网络中断恢复。
- 支持 LAN/P2P/TURN/Relay 传输、手机和平板布局、中英文界面与主题切换。

贡献者：[Mangoman2008](https://github.com/Mangoman2008)。

## 集成后的补强

- 权限确认与问答不再丢：审批可能在切到别的会话、或连接刚重连时到达，客户端会先暂存，
  重新打开会话时补发，卡片可以直接作答；主机已经作废的确认会明确显示为「已失效」。
- 连接诊断新增 Host 车道与组合指纹，能看出主机版本落在哪个能力车道、这次连接和上次有何不同。
- 修复预发布版本（如 `0.2.2-rc.1`）被误判到较低能力车道的问题，附件完整引用等能力不再误降级。
- 会话壁纸（默认虚化、三档强度）与桌宠（鲸娘，四态动画、单击说话、双击炸屏、待命睡着）可自行开启，
  素材由使用者自备、不进仓库。
- 链路日志落盘并可在诊断页查看，掉线自动重连后会自动重开会话流。
- 直连数据通道中途断开时，下一次重连会先走中继（首次 60 秒、连续两次 10 分钟内不再试直连），
  不再反复撞同一条不通的路径。
- 审批与提问在 App 处于后台时发一条系统通知（点通知直接回到 App），不用等回到会话才发现主机在等你。
- 会话列表会标出「待确认」，多个会话各挂一张卡时也能一眼看到。
- 跨连接补发出来的确认与提问，卡片上会提示「连接已重连，这条确认可能已失效」。
- 支持发送文件附件：选择文件后先上传到主机暂存，再随消息提交（单个 2.6 MB 以内）。
- 后台提醒更克制：同一条审批/提问只提醒一次（重连补发不会重复响铃），在 App 里答完或切回前台后
  通知自动消失，不会留下过期的「需要确认」。
- 点审批/提问通知会直接落到那条会话，而不是回到上次停留的位置。
- 审批与提问卡片显示已等待时长，超过 10 分钟标红提示「主机可能已超时」，一眼看出这条可能已经废了。
- 诊断页新增「通知」一行（App 内开关 / 系统开关 / 上次发布失败码分开显示）与「自检」按钮：
  一次列出连接、链路、直连、Host 能力、文件上传、通知、待确认、日志落盘情况。
- 主机返回的英文报错按规则翻成可执行的中文提示（含旧版插件、上下文超窗、主机忙、路径越界）。
- 发送失败的消息留在原位，带「重试」；断线时发送改为排队，重连回到该会话后自动补发（含附件）。
- 待发附件显示大小与合计；诊断页新增断线原因归类、RPC 质量（中位/P90）与「自检」结果。
- 诊断导出头部带上客户端/主机/插件版本、系统 API、机型与传输方式。
- 会话设置面板新增「显示桌宠」开关，首页一次点击即可隐藏/恢复桌宠。
- 回复里的 Markdown 表格按表格渲染（表头底色、行分隔、等宽列），不再显示原始的竖线和横线。
- 输入坞的文件键换成矢量图标（不再是 emoji），待发文件 chip 同步换掉。
- 思考过程默认折叠成两行，点「展开/收起」看全文。
- 代码块整段渲染（语言标注 + 单一底色，保留缩进），长按可一次复制整段。
- 会话左栏改版（参考上游）：列表按工作区分组、组头显示条数并可折叠；搜索时改回平铺、不显示分组与筛选。
- 「最近访问」收进搜索框右侧的小入口，默认收起，不再常驻占一行；工作区 chip 长按可浏览文件 / 重命名 / 删除。
- 首页（设备列表）那张会呼吸的立绘改成三选一：内置立绘 / 自定义图片 / 关闭，与桌宠开关分开控制；
  自定义图片会自动压到 512px 以内，选择时给出规格建议（PNG/JPG、约 3:4、≤1 MB）。
- 关掉首页立绘时，连它脚下的影子条一起移除，不再留一条横线。
- 支持自建服务器使用自定义端口：鸿蒙的 WebSocket 不带端口，客户端补一个完整 Origin 头，服务端按它校验（对齐官方 0.6.7）。
- 诊断页显示中继路径：独立中继时给出节点地址与节点 ID，走控制通道转发时明确标注。
- 密码登录支持两步验证：账号开了 2FA 时，输入密码后会多出「验证码或恢复码」一栏，也可点「重新输入密码」重来。
- 会话终端：设置面板里可直接打开当前会话的终端，输出滚动显示、可输入命令（暂不做完整 ANSI 着色）。
- 插件管理：设置面板里可看主机上的插件包与插件清单，点开关可启用/停用（只读项会明确提示）。
- 会员状态：设置里显示当前账号的会员（未开通 / 有效·到期日 / 已过期 / 已撤销），点一下刷新。
- DS-Bot：设置里可查看主机上的机器人与群组（主机未安装或未开放时给出明确提示）。
- 设置面板分组：账号与服务器 / 列表与布局 / 桌宠与外观 / 远程与主机 / 通知与提醒 / 外观与语言 / 高级。
- 插件设置：插件管理里每个插件可打开设置页，布尔项点一下即存，其余项改值后保存（带格式校验）。
- 终端改为 xterm.js 渲染：ANSI 颜色、清屏、光标都正常，`ls --color` / `htop` 这类不再是一堆转义码
  （内置 xterm.js 5.5.0，MIT，随包放在 rawfile/terminal/）。
- 回合进行中发送的消息会标状态：队列模式下显示「排队中 · 等当前回合结束」，插话模式显示「已插入当前回合」，
  主机确认收到后自动消失，不再出现「发出去了却没动静」。
- 排队后悔了可以「插队」：排队中的气泡上点「插队」，就地把这条改成立即插入当前回合（走 `session/updateQueue` 的 steer）。
- 排队中的消息也可以「撤回」（`session/updateQueue` 的 remove），撤回后气泡标「已撤回」，不会在下一回合被发出去。
- 排队状态收成一行：`排队中 插队 · 撤回`（同一枚淡色胶囊），已插队/已撤回各自只显示一条状态字，不再堆多个标签。
- 修插队/撤回在真机上报「endpoint is not allowed」：Host 插件的白名单里没有 `session/state`，
  改为从允许的 `session/projections` 的 inbox 投影里按 `source.rpcId` 找队列项 id。
- 再修插队/撤回的参数形状：网关要求 `session/updateQueue` 的参数包在 `request` 里，
  平铺 `sessionId/itemId/action` 会被判「args fields do not match the descriptor」。
- 修同一条消息里的图片显示两份：本机预览与主机回显的附件 id 指向同一张图，改成「有本地预览就不再补水」。
- 修带图片/文件的气泡里看不到「排队中 · 插队 · 撤回」：状态行原来与气泡横向并排，气泡一变宽就被挤出屏幕；
  改成气泡在上、状态与时间在下（纵向排列、右对齐）。
- PDF 支持全屏连续阅读（对齐 0.6.8）：预览面板右上角「全屏 / 还原」，铺满整屏后单页连续滚动。
- 修带图片/文件的消息「发出去变两份」：主机回显有时不带 rpcId，原来会新增一个气泡；现在按「同文本 + 60 秒内」兜底认领本地那条。
- 输入框补上跟随手指的淡淡光斑：之前只有图片/文件/提示词三个按键有，输入框没有，看着一半亮一半不亮。
- 顶栏主机名改成可按的圆角胶囊：点一下弹出主机列表直接切换，不用退回设备页（列表里标出「当前」）。
- 会话设置里加「文字大小」四档（小 / 标准 / 大 / 特大），点完立即重排，不用退出再进。
- 修设置里改字号不立刻生效（列表与消息行的 ForEach key 没带字号，设置面板也没重建）。
- 新增「Git 审查」（对齐 0.6.8）：列出工作区改动文件（A/M/D + 增删行数），点开看该文件 diff，
  勾选若干文件后「回传」成一条消息让 agent 继续改；主机没声明 workspace.git.read.v1 时不显示入口。
- 顶栏主机胶囊居中（左右两侧留出同样宽度）。
- 所有底部弹层（切换主机 / 会话设置 / 首页设置等）改成半透明 + 背景磨砂，透出后面的内容。
- 输入框光感改为聚焦驱动：聚焦时整条泛一层柔光，不再只有两侧按键有光。
- 桌宠支持长按后拖动到任意位置，松手弹回原位（原来长按是导出诊断，快捷键取消，诊断面板仍可导出）。
- 修顶栏胶囊与右侧图标重叠：顶栏改成 Stack，胶囊在中间层独立居中并裁剪，长标题不再压到齿轮。
- 弹层透明度再调（面板 0.52/0.62，遮罩 0.30/0.18），磨砂下面能透出会话内容。
- 输入框柔光加亮到和两侧按键同级（四档渐变、半径 220），并把 overlay 挪到绘制链末端，
  否则会被 TextArea 自己的玻璃底盖住；未聚焦时保留 50% 亮度。
- 手机竖屏顶栏隐藏「切换」二字，只留主机名，彻底避免与齿轮重叠。
