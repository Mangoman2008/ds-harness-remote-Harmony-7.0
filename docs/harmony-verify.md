# 鸿蒙客户端验收清单

> 参考 `memorax-ai/dsh-harmony` 给 agent 写 SKILL.md 的做法：把「装完怎么验」固化成步骤，
> 而不是每次临场凭记忆点。锁屏状态下 `aa start` 不加载页面，**先解锁**。

## 0. 前置

```bash
P=192.168.3.145:34521        # 手机；鸿蒙 PC 用 127.0.0.1:40601
hdc tconn $P
harmony/scripts/build-local.sh
harmony/scripts/smoke.sh $P 60
```

期望：`✅ 冒烟通过：cn.r2049.dshremote <版本> @ $P （已连接 · lan）`。

## 1. 设置项一次生效

- 主机列表右上角齿轮 → 设置；
- 点「右侧详情栏」一次，值应从「显示」变「隐藏」；
- 点「敏感内容打码」一次，值应从「开 · 点气泡看原文」变「关 · 原文显示」；
- 若要点两次：检查桌宠浮层是否盖在面板上（`PetWidget` 的 `hitTestBehavior`）。

## 2. 会话壁纸

- 会话标题旁齿轮 → 会话设置 → 会话壁纸 →「选择」调相册；
- 选完点「切换」，压暗强度在 淡/中/浓 之间循环，背景应立刻变化；
- 重启 App 后强度应保持（`wallpaperDim` 落盘）；
- 应用设置里不应再有壁纸入口（已挪到会话设置）。

## 3. 桌宠（鲸娘）

- 点一下：出俏皮语气泡（按 干活/等确认/刚做完/待命 四种状态取词）；
- 连点两下：炸屏（580ms 冲出 → 停 800ms → 680ms 缩回）。**合成点击不可靠，必须手点**；
- 静置 3 分钟：切睡觉姿势，点一下会醒；
- 素材缺失时应自动退回 emoji 桌宠（删掉 `rawfile/pets/` 再构建可验证）。

## 4. 诊断

- 设置 → 连接诊断；
- 应看到 `Host 车道：<版本> · <车道> · 能力 …`、`组合指纹：…` 两行；
- 与上次组合不同时会多一行 `上次组合：…`，链路日志里也会有 `combo` 事件。

## 5. 图片链路

- 电脑网页发一张 JPG/PNG → 手机端应显示；
- 发 HEIC → 显示成 `📎 名称 · 大小` 卡片（主机不收该格式）；
- 消息里出现 `![](/主机/路径)` 的图片 → 能读到就显示，读不到给「图片加载失败 + 重试」，不再无限转圈。

## 6. 图片预览手势

- 点开任意图片 → 双指放大；
- 放大后单指拖动：跟随手指，放大越多拖得越快（1.5 倍基准、封顶 4 倍）；
- 拖到边缘停住，不会被拖出屏幕。

## 7. 权限确认（审批 / 提问）不丢

上游 `client-core` 在会话(重)开时补发未作答的交互帧；鸿蒙客户端以前只在到达时发一次，
于是审批在你翻别处、或刚重连时到达就永久消失。验收：

1. 在会话 A 里发一条会触发审批的指令（例如让 agent 往工作区外写文件）；
2. **不等审批出现**，立刻切到会话 B；
3. 等 10–30 秒，再切回 A → 审批卡必须出现，「允许 / 拒绝」能点，点完变「已允许 / 已拒绝」；
4. 断线重连后重复第 3 步：断线期间到达的审批，重连并重开会话后同样要能补出来；
5. 日志应有 `replay pending interactions session=… n=1`（`hdc shell hilog -T DSHREMOTE`）；
6. 补发出来的卡片如果主机那头早已撤销，点它会显示「已失效」，不会一直转圈或留死卡。

实测 2026-11-16（0.17.158-lan，手机 PLU-AL10 → 主机 DESKTOP-R5BVQJJ/win32）：

- 新会话发「往 `C:\Users\Chow\AppData\Local\Temp` 写文件」→ 主机先按沙箱拒绝一次，
  随后申请 `danger-full-access` 升级（`approval/request`）；
- 审批到达时 App 正停在另一个会话上，两分钟后才切回该会话 → 审批卡出现且可点；
- 点「允许」后卡片变「已允许」，主机侧命令继续执行。App 进程自 00:18 起未重启，
  所以这张卡只可能来自新增的补发路径（改动前该帧在 `handleFrame` 里按会话过滤丢掉）。
- 未覆盖：断线重连期间到达的审批（当时手机锁屏，`hilog` 未抓到
  `replay pending interactions` 那行）。

0.17.159 起给作答链路补了日志（`approval/requested … 当前会话=`、`respondApproval 点击
… 卡片还在列表里=`、`respondApproval 失败 … : 原因`），失败时一律把卡片标成「已失效」。
2026-11-16 00:40 实测（正常路径，未断线）：审批到达 → 点击 → 79ms 内 `respondApproval 已提交`；
同一会话 00:41/00:42 两次回前台体检均无重连。
